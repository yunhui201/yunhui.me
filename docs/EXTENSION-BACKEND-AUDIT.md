# 扩展后端本地检查（2026-11-15）

本轮检查 `src/core/extensions`、随附扩展资源调用契约和 `scripts/test-extensions.mjs`。未修改 `third_party` 原始资源。仅使用临时客户端目录、模拟下载和独立隐藏 Electron 窗口；未连接真实 Codex/ChatGPT 进程、修改真实客户端配置或产生供应商 API 费用。

## 已修复

- 市场安装、启停、移除：客户端 TOML、市场清单和安装记录统一提交与失败回滚；保留其他插件和供应商设置。共享 `applyPlan` 同时检查每次写入前状态，回滚遇外部改动保留该文件并提示人工检查。测试覆盖后续记录写入失败、事务中外部改动、移除失败。
- 安装与缓存：重新安装也验证 Git tree 和每个 blob，拒绝被篡改的同版本缓存；安装过程中同一插件禁止启停/移除。卸载保留源码及许可证缓存，重装可复用校验通过的缓存。
- 市场状态：本地版本与目录版本分离，提供 `availableVersion` / `updateAvailable`；目录下架仍显示本地记录，可停用/移除。原生市场 installed/list/read 桥接也保留下架项目；刷新实际更新目录。
- 缺失文件：检查包目录及普通 manifest 文件、名称和版本，不再仅检查路径存在。`installed` 表示安装记录；`packagePresent` 表示上述存在性检查通过。缺失或清单无效时禁止启用，但允许停用和移除。
- 运行时：注入失败会使连接失败并清理，整体未就绪不显示扩展 active；错误可经状态返回。桥接设置与云汇 UI 互斥写入，原生设置变更安排实际重载，避免只有保存状态变化。失败或停用时取消历史分页轮询、光标同步和在途构造器捕获；Debugger enable 与停止交错不会遗留 Debugger。
- 会话用量：缓存按客户端根目录隔离，命中缓存时重新核验 session_meta；跳过符号链接及不可读候选、严格限制扫描数量。真实 0 与未知缓存计数继续分开。
- Work 视图：客户端配置、恢复记录和扩展开关统一事务，失败不会丢失恢复基线。
- Profile 识别：Work 视图、Fast 与输入预测使用完整 TOML 解析，支持带点/中文的引用键、旧版活动 profile 表继承根供应商、同名供应商逐字段覆盖。配置读取限制为普通文件、4 MB；无效 profile/TOML 不误报 API 已配置，解析错误不回显密钥内容。
- 扩展会话查询：补全上游 `sessionQuery` 的 10 个只读方法，包括归档/目录/创建时间筛选、游标搜索、事件窗口、增量读取。优先从只读原生 `threads` 读取改名后的标题及元数据；无原生索引时使用现有日志扫描回退。`readSession` 返回 `{ session, events }`；事件保留稳定 `seq`、工具调用 ID/输入/输出、消息 phase、用量和轮次完成信息，过滤注入上下文及加密推理。上游订阅及工具视图不再因缺方法或缺字段失败。
- 会话归档：原生归档前先保存撤销记录；磁盘写入失败不执行归档。撤销令牌严格校验；恢复成功而清理记录失败时明确说明。仍是原生 archive/unarchive，不删除会话文件。
- 配置校验：拒绝未知 schema 类型；桌宠未接入的自定义/下载音效、额外图库和自定义余额接口拒绝保存。语音重载取消在途请求，旧请求结束不会清除同 ID 的新请求。

## 实际边界

- 原生桌面不同版本的 DOM、模块和 app-server 私有能力仍需兼容性验证。本轮未在真实个人客户端上作带账号的端到端操作。
- 市场测试验证所选包的安装管道，未下载/执行全部 5,491 个包；插件服务 OAuth、MCP、hooks 等依赖插件自身和客户端，安装默认关闭，启用后通常需重启。
- 列表的 `packagePresent` 不是完整文件哈希证明。完整 Git 内容验证在安装/重装时执行；已存在同版本缓存被改动时停止覆盖，提示手动检查。不会静默销毁本地修改。
- `side-chat-save`、微信同步、按上报用量压缩、浏览器请求标识、官方额度入口兼容仍为 unsupported。不会假启用，也不增加官方服务端额度。
- 桌宠鲸鱼余额/历史统计接口、桌宠自定义音效导入、上游管理器打开未接入，返回明确 unavailable/错误。图片、内置 duck/fx1 音效可用。
- ASR 和下一步建议需要配置兼容供应商/模型；正常使用会按供应商规则消耗额度。本轮只验证协议适配和模拟返回。
- 原生 Fast、预测、历史分页和原生桌宠跟随鼠标取决于实际客户端能力。Work 视图写配置后重启生效；回答后折叠思考仅作用于经过云汇网关的 Responses 请求。
- 五个扩展的 loaded 表示脚本加载成功，媒体或服务仍可能后续不可用；背景图片须已选择有效本地文件，远端图片须可下载。不能把脚本加载等同所有服务已经授权。
- 扩展事件查询有明确资源边界：日志最多 256 MB、200,000 条事件、64 MB 解析结果，超过时直接会话查询报错；单条文本按上游契约最多保留 20,000 字。缓存总量最多 32 MB。跨会话事件搜索遵循上游行为跳过无法读取的日志；原生索引最多 50,000 条/库，无索引时受现有日志扫描范围限制。查询仅接受当前 Codex 根内的普通 JSONL，并核对日志 ID，不修改历史或索引。
- 旧版 `profile` / `[profiles.*]` 表的继承与覆盖仅通过本地配置 fixture 验证；真实 Codex CLI 0.169 已改用 `--profile` 与独立 profile 配置文件，并拒绝旧表。扩展配置检查当前读取根配置及旧表，不能仅凭根配置推断外部进程通过 CLI 参数选中的新文件 profile；不将本地解析成功表述为所有原生版本均兼容。
