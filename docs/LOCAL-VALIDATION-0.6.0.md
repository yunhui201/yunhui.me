## 本轮完成

- 本机已有 API 配置在启动、每 30 秒和窗口重新获得焦点时扫描；非强制扫描有 5 秒节流。支持来源去重、模型合并、明确重新导入，以及手工修改和删除保护。
- 官方登录单独显示状态。ChatGPT 编程模块 / Codex CLI 的接入向导可选择官方或第三方模型；托盘切换保留已经应用的共存模式。
- 共存请求分别使用官方或供应商鉴权；不改写 `auth.json`，不把 OAuth 转为普通供应商密钥。官方模型目录来自同账号的真实本机缓存。
- 应用、切换和恢复时一次保存共享客户端状态；状态写入失败则撤回本次配置及模型目录变更，保留首次备份。检测到外部修改时保留该修改并提示处理路径。
- 扫描失败在页面展示原因；手动模型 ID 先保存再预览，避免无法完成配置。
- 历史会话按原生供应商区域筛选，支持来源到目标的部分或批量迁移；插件市场、桌面扩展及网关中间件完成专项检查与修复，见 [本轮检查记录](PLUGIN-HISTORY-AUDIT.md)。
- 设置页隐藏供应商目录地址、验证按钮及自动模型同步开关；启动时刷新目录并保留缓存，供应商保存后有启用密钥即同步模型。旧设置和导入备份统一迁移，远程控制台的脱敏密钥也能正确触发同步。
- 更新默认查询 GitHub 最新正式版并匹配平台和架构，失败自动查询官网；客户可手动选择官网备用，版本落后或缺包时提示原因。检查后由客户点击下载，拒绝降级和跳转到网站后台。见 [更新规则](UPDATE-CHECK-VALIDATION.md) 和 [界面验收](UPDATE-UI-VALIDATION.json)。
