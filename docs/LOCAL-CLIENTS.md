# 本机配置发现与官方账号

程序启动时扫描已支持的配置，运行期间每 30 秒检查一次，切回窗口也会检查；非强制检查有 5 秒节流。「检测本地客户端」和「我的供应商 → 重新扫描」立即读取。

当前识别 Codex CLI / ChatGPT 编程配置、Claude Code、Claude Desktop 的 Gateway profile、Gemini CLI 与 Qwen Code 的环境文件、明确声明的 OpenCode JSON 供应商。完整 TOML 会按当前 profile 与供应商表解析，环境密钥只读取现有进程变量；不会运行 Key Helper 或配置中的命令。不认识的格式说明原因，保留源文件。

Codex 配置按 `CODEX_HOME` 或用户目录下的 `.codex` 读取，不要求先找到桌面主程序。单条已知的非凭据图片扩展标记可与 Bearer 配置一起识别；未知、重复、动态或额外认证头仍需手动确认，标记不会被当作 API Key 或自动开启图片能力。

有效 API 配置按接口、协议和密钥去重加入供应商列表，卡片显示对应客户端及配置来源。普通扫描不发送模型请求。新增模型会合并到导入项；已有模型及能力、价格元数据保留。供应商被用户修改后，不再用源配置覆盖它。删除导入项会留下本机来源记录，重启及重新扫描不会复活；可在扫描详情中明确选择重新导入。删除源文件也不会删除已导入的供应商。

云汇自己的网关配置和托管 provider/profile 会跳过，避免将网关再次作为上游造成循环。来源记录损坏时暂停导入；读取或保存失败会在界面说明。

官方 OAuth 显示在独立的本机账号卡片中，状态区分「已检测到凭据」「本地凭据已过期」「仅发现登录记录」与「状态未知」。检测记录不代表在线订阅仍有效，也不会把 OAuth 当作 API Key 加入供应商。账号登录、退出和续期继续由官方客户端完成。

ChatGPT 桌面版的编程模块和 Codex CLI 可在接入向导勾选「保留官方账号并与第三方模型共存」。官方模型来自本机真实目录，并与第三方模型按来源分开；需要有效的本机登录记录和已加载过的官方模型目录。原登录文件始终不改写。详见 [共存配置与验证范围](CODEX-COEXISTENCE.md)。

本轮为本地 Windows 功能验证，未发布包含这些新增功能的正式版。自动发现、官方身份分离及界面流程已有隔离测试；真实官方客户端各版本的菜单和远端权限仍需要实际联调确认。
