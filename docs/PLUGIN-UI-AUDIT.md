# 插件界面审计

核对日期：2026-11-15。范围为 `DesktopExtensions.tsx`、`Plugins.tsx`、`CodexEnhance.tsx`，并按 实际随附包清单、配置约束和后端接口核对行为。本次没有连接、注入或修改用户真实 ChatGPT / Codex 客户端。

## 已修复的界面问题

| 问题 | 修改后行为 |
| --- | --- |
| 背景图包采用 `type: string, format: file`，原界面只识别 `type: file` | 两种声明都显示“选择图片”；文件选择错误直接显示在设置弹窗中 |
| 设置、连接和卸载失败只显示在弹窗后面的页面 | 失败信息显示在当前弹窗，保留输入和重试入口；操作失败后重新读取实际状态 |
| “全部插件”下同步市场只更新公开库 | 同步两个市场；选定公开库或完整索引时只同步对应来源 |
| 旧版本已启用的暂不兼容增强无法停用 | 允许关闭已有启用项；继续禁止启用尚未适配的能力 |
| Agent 桌宠直接暴露上游尚未接入的自定义音效、余额接口设置 | 显示当前支持边界；普通表单仅提供已实现音效，隐藏无效余额及自定义音效字段；高级 JSON 继续由后端验证 |
| 市场更新后安装版本不明确、下架或缺失文件的插件难以管理 | 使用后端的安装版本、可用版本、更新、缺失文件、下架标记；提供更新、修复安装和本地管理入口；移除说明明确保留源码与许可证缓存 |
| 切换到新客户端版本后可能沿用此前的兼容确认 | 版本变化会清除确认，必须针对当前版本重新确认 |
| 网关中间件只显示“已启用” | 分别显示等待请求验证、最近运行正常、失败或主动拦截，以及验证时间；停用时隐藏旧运行结果 |
| 旧坏中间件无法通过开关停用 | 已有记录的开关只发送 `id` 与 `enabled`，由后端独立验证状态变更 |
| 桌面资源库的原客户端插件目录与云汇插件市场容易混淆 | 增加“管理云汇插件”入口；读取失败保留最后一次资源列表并显示错误 |
